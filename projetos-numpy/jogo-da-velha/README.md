# Jogo da Velha com NumPy

Projeto desenvolvido durante meus estudos de **Python e NumPy**, utilizando uma matriz para representar o tabuleiro e controlar as jogadas.

## Tecnologias

- Python
- NumPy

## Conceitos praticados

- Criação e manipulação de arrays
- Matrizes e indexação
- Funções
- Estruturas condicionais
- Validação de jogadas
- Verificação de linhas, colunas e diagonais
- Tratamento de erros com `try/except`

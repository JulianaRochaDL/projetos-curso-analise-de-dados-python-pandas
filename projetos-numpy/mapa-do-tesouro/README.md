# Mapa do Tesouro com NumPy

Projeto desenvolvido durante meus estudos de **Python e NumPy**, utilizando uma matriz para representar o mapa e controlar a movimentação do jogador em busca do tesouro.

## Tecnologias

- Python
- NumPy

## Conceitos praticados

- Criação e manipulação de arrays
- Matrizes e indexação
- Geração de números aleatórios
- Funções
- Estruturas condicionais e de repetição
- Dicionários
- Validação de movimentos
- Controle de pontuação
